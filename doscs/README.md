# Documentation

This section contains documentation related to the **laboratory architecture** and **security incident reports** generated during testing.

The laboratory is built and managed using **VMware** as the virtualization platform for the virtual machines. A **domain managed through Cloudflare and Cloudflare Tunnel** is also used to expose selected laboratory services to the Internet without requiring a public IP address directly on the infrastructure.

The documentation is mainly divided into:

* **Architecture:** infrastructure, network topology, components, and communication flow.
* **Incidents:** attack scenarios, generated alerts, investigation, evidence, and response actions.
