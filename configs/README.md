# Configurations

This section contains the configurations implemented throughout the project, covering the infrastructure components deployed across the **DMZ and LAN environments**.

Each directory corresponds to a specific component of the laboratory and contains its respective configuration, along with documentation explaining **what was configured, why it was configured, and how it was implemented**.

The configurations are organized as follows:

* **Wazuh Server:** SIEM configuration, log collection, detection rules, decoders, and security monitoring.
* **Nginx / VPN Server:** Reverse proxyr and VPN-related configuration.
* **Web Server:** Web service and application configuration.
* **pfSense:** Firewall rules, NAT, routing, and network security policies.
* **LAN:** Configuration related to the internal network and its components.
